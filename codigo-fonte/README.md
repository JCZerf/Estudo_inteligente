## 🌐 Instalação do Site

O site **Estudo Inteligente** é um projeto estático (HTML, CSS e JS). Para visualização pública, é necessário implantá-lo em um servidor web. Recomendamos o uso do [GitHub Pages](https://pages.github.com/) neste primeiro eixo.

### Como executar localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ICEI-PUC-Minas-PMV-ADS/pmv-ads-2025-1-e1-proj-web-t8-grupo-2-estudo-inteligente.git
   ```

2. Navegue até a pasta `src/`:
   ```bash
   cd pmv-ads-2025-1-e1-proj-web-t8-grupo-2-estudo-inteligente/src
   ```

3. Abra `index.html` em um navegador moderno.

> 💡 O projeto também pode ser hospedado em Vercel, Netlify, Render, Surge.sh, entre outros.  
> 🔗 [https://icei-puc-minas-pmv-ads.github.io/pmv-ads-2025-1-e1-proj-web-t8-grupo-2-estudo-inteligente/]
